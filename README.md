# TelecomX – Análisis de Churn

## Descripción
Este proyecto analiza la evasión de clientes (Churn) en TelecomX utilizando Python.  
El objetivo es identificar patrones en el comportamiento de los clientes que puedan estar asociados con la cancelación del servicio.

## Tecnologías
- Python
- Pandas
- Seaborn
- Matplotlib
- Google Colab

## Análisis realizado
- Limpieza y transformación de datos
- Análisis exploratorio
- Visualización de patrones de churn
- Identificación de factores asociados a la cancelación
